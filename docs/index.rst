Welcome to the Ersilia API Documentation
========================================

The **Ersilia API** empowers developers and researchers to integrate state-of-the-art computational biology models into their applications and workflows. By leveraging the Ersilia platform, you can access a wide array of pre-trained models for tasks such as drug discovery, disease modeling, and molecular property prediction.

This documentation provides comprehensive information on the API's functionalities, including detailed descriptions of classes, methods, and modules backed by examples. For user guides, see the `Ersilia Book <https://ersilia.gitbook.io/ersilia-book/>`_.

.. note::

   This documentation is generated automatically with AI and CI. The reference pages are built from the source code by a GitHub Actions workflow on every change to ``master``, and the docstrings they are built from are written and maintained with the help of AI.
