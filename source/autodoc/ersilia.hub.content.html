ersilia.hub.content.information.version_label(docker_tag, card)[source]¶

The version to show for a model image, e.g. “latest (v1.0.1)”.

Parameters:

  • docker_tag (str) – The Docker image tag, often “latest”.

  • card (dict) – The model card; its “Release” field gives the actual version.

Returns:

The tag, with the release in parentheses when the tag is “latest”.

Return type:

str or None

ersilia.hub.content.information.write_fields(data, output)[source]¶

Write a flat dictionary (model information or card) to a file.

Used by ersilia info -o, ersilia catalog --card -o and the Python API, so that all of them write the same format.

Parameters:

  • data (dict) – The fields to write.

  • output (str) – Path ending in .json (pretty-printed JSON) or .csv (two columns, Field and Value; list values are joined with commas).
